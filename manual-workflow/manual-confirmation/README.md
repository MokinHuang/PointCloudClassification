# 人工工作帮范围确认工具

固定基线：`9d3d2cc34f31273296e487b9cd7e47b63f4d51bc`。本目录是独立新增模块；基线 C++ 源码不变，无自动工作帮识别依赖。

## 打开与完整演示

双击交付目录中的 `workface-confirmation.html`，可离线运行，不需要服务器或第三方网络资源。

1. 新建工作帮。在“原线”选择坡顶 **28** → “加入上边界”；坡底 **299** → “加入下边界”。也可在地图点击，滚轮缩放、拖动平移。
2. 每个已加入条目可编辑原线累计里程起止。可再加入不同原始编号，或把同一原线拆成不相连的有效区段。不会连接区段间断口。先选中某个区段，再把地图模式改为设起点/终点，即可点击裁切。
3. 点击“按已选边界设置方向和范围”。方向仅为便捷初值，请依据矿区真实坡向核对。左右站位控制同一组平行剖面的横向范围；下坡方向以局部 +X 轴为 0°、逆时针计角。
4. 点击“生成 / 更新剖面”，然后“定位选中边界”。示例默认 5 m 间距得到 41 个剖面、39 个有效。此范围用于操作演示，**不是已确认生产工作帮**。
5. 逐个查看端点与高程剖面。点击“排除 / 恢复当前剖面”可保留排除记录；异常剖面不会进入参数统计。调整范围或排除剖面会撤销确认，改变范围会清空旧剖面排除编号，避免套用到新站位。
6. 实际生产范围应由有现场依据的核验人确认。填核验人后勾选确认；本工具不替用户证明生产范围或原始几何精度。
7. 导出记录 JSON，重新打开网页后加载。可直接加载交付中的 `demo-confirmations.json` 查看预设示例草稿。浏览器备份仅作方便使用，建议始终另存文件。
8. 导出剖面 CSV 与统计 JSON；完整计算依据 JSON 包括每个交点的原线编号、原始顶点段、插值比例、地形采样、失败原因、排除标记、输入哈希及确认记录。
9. “关联参数与评价状态”中可复核、导出既有台阶/平台参数。草稿不会正式关联；跨多个工作帮或包含失效/排除剖面空白的测线保持未确定。

## 计算与拒绝规则

- 论文已核对工作区保存的第 4 页图 5：H1 工作帮高度、L1 工作帮水平距离、φ 工作帮坡角。同一剖面的 H=Z上−Z下，L=两端 XY 距离，φ=atan2(H,L)。绝不使用区域任意最高/最低点。
- 本工具是人工确定范围后的平行剖面测量方案，不是论文中线法向识别的严格算法复现。弯曲范围可分成多个工作帮区段，分别选择测量方向。
- 上边界必须坡顶、下边界必须坡底；原线高程不可编辑。高程仅在原线相邻顶点间线性插值。
- 上下边界交叉时保守拒绝当前所选几何，需用户裁去交叉段；不自行选择另一交点。重叠、多重交点、缺交点、反向或高程顺序不对均不输出有效参数。
- 剖面遍历穿过的网格单元，只有 count>0 算有观测。任何沿程或端点缺测都不纳入有效统计；不使用已填补但没有观测计数的高程。
- 缺测比例 = 边界缺交点或地形缺测剖面数 / 全部剖面数。多交点、交叉、配对失败及人工排除另计在非有效比例中，不能把有效数量当精度。
- 既有参数关联首先按原线编号/区段复算端点（容差 0.02 m，兼容历史浮点输出）及参数（容差 0.001 m/°），验证有观测。之后要求整条测线位于连续有效剖面形成的范围内、无排除或失效断带、唯一归属已确认工作帮。导出原表文件 SHA256、行号身份及原线哈希。没有可靠引用的旧表继续未确定；这里的关联不是历史测量精度认证。
- 设计限值为空，SMSI为空，最终安全评价未完成。不套用默认限值。

## 数据绑定

数据集 ID 由 `classification.csv`、`feature_lines.csv`、`grid_origin.txt` 三文件 SHA256 清单再哈希生成；每个边界引用同时保存原线几何哈希。导入会检查版本、数据集、编号、边界类型、区段范围、数值和排除索引。不匹配时拒绝整份记录并保留当前状态。修改文件换行也会改变指纹，这是刻意采用的保守绑定。

## 从其他结果生成网页

Python 3 标准库即可。运行：

```powershell
python manual-confirmation/build_viewer.py <包含三份输入的目录> <输出HTML路径> --measurements <既有参数CSV目录>
```

`--measurements` 可省略。支持含 `crest_line_id`、`crest_station`、`toe_line_id`、`toe_segment`、`toe_fraction` 的 `matched_sections.csv` 和 `platform_widths.csv`；来源引用无法复核则不关联。程序只读输入，不重新分类、提线、识别自动工作帮或回写旧结果。

## 范围限制

没有重跑原始 PCD；原 E 盘文件不可用，本次只回放工作区已有网格和特征线。没有进行自动工作帮识别试验，也没有做独立人工检验点误差实验。没有重编译原 C++：本次新增的是独立离线工具，固定基线源码保持不变。复杂曲线需要人工分区选择方向；没有原线修复或高程编辑。HTML 内嵌全场数据，文件约数十 MB，加载性能受设备影响。
