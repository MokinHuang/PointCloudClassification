# 人工确认工作流（独立于自动工作帮识别）

本目录从固定提交9d3d2cc34f31273296e487b9cd7e47b63f4d51bc建立，保留独立分类/特征提取主程序，避免依赖PR根目录的自动工作帮分组。根目录原自动识别版本保留作参考。

- manual-confirmation：多原线区段范围、平行剖面、人工平台、用途、确认记录、数据集SHA256绑定、排除与参数/审计导出。
- Pointcloudclassification/FeatureGapRepair.h：保守短断口及局部方向拟合。
- build.cmd/run.cmd：原始PCD分类、特征提取及台阶/平台测量；不进行自动工作帮识别。
- build_gap.cmd：构建独立修复与23项专项测试。
- gap_replay.exe INPUT OUTPUT：30度默认策略；附加--local-fit启用局部2/3网格尺度拟合；--wide-270表示最大偏差135度（总范围270度）。其他地形/高程/唯一性约束保留。
- generate_viewer.cmd INPUT OUTPUT_HTML [MEASUREMENTS]：生成离线确认网页；viewer.html是模板，不能直接打开。
- tests：计算与浏览器测试。浏览器测试保留开发机环境路径和数据样本编号，需本地数据及调整路径；不是可直接在CI运行的通用测试。

验证记录：71,570,574点新PCD生成1541条线、6662台阶配对、3155平台测量。补线旧版35、局部方向版47、270度版119（相对47新增73、端点竞争撤销1）。79218原顶点保留，输入CSV哈希不变。23项C++修复测试和JS计算测试通过，浏览器加载/记录恢复/错误数据集拒绝/导出与补线对比经本地验证。计数不是精度。

边界：推断补线不直接替换正式测量输入。平台所属工作帮是人工声明，归属仍需复核。设计限值缺失留空；SMSI及最终安全评价尚未完成。没有完成原始点云独立精度验证。

后续方法2：在另一分支从原始点云构建不受围堰分类改写的独立地形表面，沿局部剖面寻找主坡顶/坡底转折。先诊断候选120，不直接全场替换。原分类流程保留对照。
