# 特征线保守短断口修复（2026-10-21）

## 使用

运行 `build.cmd` 编译；`run.cmd 输入.pcd` 在现有流程之外自动输出修复结果。
已有 `run-output/classification.csv`、`feature_lines.csv`、`grid_origin.txt` 时，可直接运行 `repair_features.cmd`，无需重新分类。

开发验证：`build.cmd test`。独立回放：`build/gap_replay.exe 输入目录 输出目录`。
离线核验页：`python gap_report.py 输入目录 输出目录`，标准库即可，生成 `feature_gap_review.html`。

## 当前规则

同类、不同线的开放端点才成为候选。默认 XY 距离 <=5 m；两端各用至少 5 m 的线段估计外向切线，方向偏差 <=30°；双向预测高程残差 <=0.75 m。
沿补线每半个网格检查实际观测，每处须在 1.5 m 内找到高程一致的同类边界标记。
端点距离其他线段 <=0.3 m 视为已有交汇，拒绝连接。拒绝跨线、多候选歧义、补线间交叉、闭环。
参数位于 `Pointcloudclassification/FeatureGapRepair.h` 的 `Options`，是本数据集试验值，不是论文或规范限值。

## 输出及安全边界

- `feature_lines.csv`：原有线保持不变；仍用于正式坡面、平台、工作帮计算。
- `feature_lines_repaired.csv`：真正拼接后的有序折线，保留全部原顶点。被拼接线的输出 ID 取遍历起点所属原线 ID，不能再将旧 ID 直接套到新线。
- `feature_gap_candidates.csv`：每个半径内同类端点候选及拒绝原因、端点坐标；被前置条件拒绝的未计算指标为 0，不能当作测量值。
- `feature_gap_provenance.csv`：每个输出顶点的原线/原点编号；`incoming_inferred_bridge_id>=0` 代表到该点的上一条边是推断补线，-1 代表非补线（含折线首点）。
- `feature_gap_review.html`：原线和洋红补线叠加，支持开关前后比较、端点显示、逐候选定位、缩放平移。

本版不改坡顶坡底提取、平滑、围堰分类，不把推断边自动当成实测边。核验补线后，再设计测量对推断区的排除或质量标记；不要用修复 CSV 覆盖原文件。
5 m 以外缺口、短分支、急弯、无观测处可能仍不连接；截图中的连续折线弯折不会被当作断口。

## 验证

76 项 C++ 测试通过（新增 15 项，历史 61 项）。历史全场网格回放得到 361 候选、9 接受；513 条线变成 504 条，27,537 原顶点逐点来源验证通过。
9 条补线长 2–3.16 m；方向拒绝 202、高程趋势 11、已有交汇 18、边界支持 2、短/弯切线 118、无观测 1。
核验页浏览器自动检查通过。该结果来自保存的网格和线，不是重新读取原始 PCD；尚无人工真值精度指标。

工作计划、发现、测试日志位于工作区根目录的 task_plan.md、findings.md、progress.md。

## 当前迁移入口（以此为准）
使用build_gap.cmd编译并运行15项专项测试；repair_features.cmd 输入目录 输出目录执行独立修复和生成核验页。当前主程序main.cpp不自动调用修复，原参数仍用原线。原文历史build.cmd/run.cmd说明仅适用于旧版。

局部方向复核版（2026-11-03）
使用 app/build/gap_replay.exe 输入目录 输出目录 --local-fit 开启；不带该参数保留旧方向策略。之后用 python app/gap_report.py 输入目录 输出目录 生成对比页。
仅重审 direction 和 short_or_curved_tangent：沿原线弧长在2倍与3倍网格尺度拟合XYZ，至少3点、2倍网格长度；两尺度方向差不超过15度，XY拟合残差<=0.35倍网格、高程残差<=0.35m。桥接方向仍限制30度、高程外推残差仍限制0.75m。阈值属于工程筛查参数，不是安全规范。
所有新连接继续检查沿途观测、同类边界支持、已有线交叉、端点唯一性、候选交叉和闭环；无全量强连。
结果：旧35处全部保留，新12处（短线类11、方向类1），合计47处。原方向类593处仍方向不符；原短线类278处可估方向但方向不符、40处拟合不足、其余按高程/交汇/观测等拒绝。79218原点来源检查通过，输入CSV哈希不变。
19项专项测试和新版网页加载/补线切换/定位通过。测试脚本末尾输出的35为沿用旧脚本的文字，实际加载断言为47。没有真实人工标注精度验证。补线仅供核验，不进入正式参数。

270度范围独立实验：gap_replay.exe 输入目录 输出目录 --wide-270；最大偏差135度，总允许范围270度，localFit开启，其余筛查保留。旧无参数/--local-fit仍为最大偏差30度。
