# 点云分类、台阶测量与工作帮范围核验

本版在台阶配对及平台宽度测量基础上，增加特征线断口修复、网页边界选择、自动多台阶工作帮候选及上下界追踪。

## 编译和运行

使用 Visual Studio 2022 Release/x64 或运行 build.cmd。脚本和属性表按本机 PCL 1.15.1 安装路径配置，其他机器需调整依赖路径。将 PCD 拖入 run.cmd，输出位于 run-output；重复运行会覆盖同名输出。

生成结果后，可用 review_bottom_workfaces.cmd 打开贯通候选。上界核验页面为同一结果目录中的 upper_trace_resolved_workface_review.html。基础人工选择流程见 README-workface-range.md；上界追踪说明见 UPPER_TRACE.md。

## 已实现

- 网格分类、围堰识别、坡顶坡底特征线提取与断口修复诊断。
- 单台阶配对及高度、坡面角、水平距离；平台宽度及独立长平台候选。
- 网页特征线选择、坡面点击联动、边界配置导出及剖面预览。
- 多台阶分组、候选归属、连续区段、逐级贯通和上下界追踪。
- 保留原坡顶编号、上溯链、局部平台验证及未通过原因。
- 论文风险规则和设计值模板输出。

## 尚未完成

自动工作帮仍存在漏识别及上下界不完整。局部几何、通过当前检查的候选和真实生产工作帮不是同一概念。上界核验页用虚线保留未确定范围，不能将虚线起点直接用于整体工作帮评价。

多段边界人工裁定、确认记录持久化及确认后最终参数的完整网页流程尚未实现。SMSI和最终安全评价未完成；历史 SafetyCalculator.cpp 未纳入主程序构建，不应独立运行它来宣称完成评价。跨矿区识别正确率尚未验证。

## 本版验证

开发副本通过主程序构建、原76项基础测试及归并/解析/上界追踪测试。矿区回放中25个既有测量CSV保持一致。上界追踪8条成功延伸，其中1条通过全部检查；28条上界未定，最终63条贯通候选。上述数量仅对应本次样本，不能解释为准确率。

仓库交付源码、构建/运行脚本及说明，不包含PCD、编译产物、生成结果或测试数据。
