# 点云分类与边坡参数测量：纯源码版

基于当前 platform-adaptive 长平台候选试验版，导出日期 2026-10-18。算法源码保持不变，未覆盖原开发目录或 E 盘工程。

仅保留 C++ 源码、Visual Studio 工程、依赖属性表和编译运行脚本。不含测试代码、测试结果、验证绘图脚本、复算工具、点云数据、历史对照数据或编译产物。build.cmd 仅编译主程序，无测试入口。

## 使用

1. 用 Visual Studio 2022 打开 Pointcloudclassification.sln，选择 Release/x64；或运行 build.cmd。
2. 编译脚本与属性表按本机 VS2022 Community、D:\ComputerVisual\PCL\PCL 1.15.1 配置。安装路径不同需修改对应配置。
3. 使用脚本编译后，将 PCD 文件拖入 run.cmd，或传入其完整路径。运行时会创建 run-output 并输出测量文件；重复运行将覆盖同名输出。

## 功能范围

分类与围堰识别、坡顶坡底线提取、坡面配对及高度/坡角计算、平台宽度测量、扩展长平台候选审核。

长平台候选仍单独写入 review_ 前缀文件，未加入正式平台测量。工作帮坡角尚未实现；SafetyCalculator.cpp 为保留的历史代码，未加入当前主程序构建，不代表已接入安全评价。

程序正常运行时仍会生成测量结果和诊断数据；本次移除的是交付包中的已有测试文件及结果，不是删除程序的输出功能。
