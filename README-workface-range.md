# 工作帮范围确认（2026-10-22）

## 直接使用

1. 主程序完成 PCD 处理后，打开 `run-output/workface_range_review.html`。
2. 已有运行结果时，无需重新处理点云：双击 `confirm_workfaces.cmd`。也可将包含 `classification.csv`、`feature_lines.csv`、`grid_origin.txt` 的文件夹拖到脚本上。
3. 独立生成器输出在该结果文件夹的 `range-review/workface_range_review.html`。用 Edge/Chrome 打开。此入口不会覆盖原参数、设计值模板或 JSON。
4. 源码包先运行 `build.cmd`；独立工具包已包含编译后的 `build/workface_range.exe`。运行脚本在出错后保留窗口。

## 核验流程

- 在“自动候选”选择一项，点击“定位当前范围”。橙色高亮所选上部坡顶区段，青色高亮下部坡底区段，黄色是中间台阶边界参考线。
- 逐项检查台阶链：它从上到下排列，列出每级坡顶/坡底编号及相邻平台支持数量。它不是仅凭编号相邻建立的关系。
- 上部坡顶必须是工作帮最上部台阶的坡顶，下部坡底必须是最下部台阶的坡底。自动候选图的首尾可能由漏配形成，不能直接认可。
- 需要调整时，更换上下边界，点击“查找两边界之间的台阶链”。多条路径时须明确选择；没有可靠路径时只能保存草稿，不强制跨断点。
- 上下边界都有自己的沿线起止距离。可输入距离，也可在“地图点击”中选择起止点模式后点击已选边界。两条线的顶点方向可以相反。
- 默认下部范围是整条下界，不表示已核实整个范围。请检查是否需要缩短。中间黄色整线仅作参考，不表示整条线属于该范围。
- 填写核验人，核实并勾选三个确认项，然后点击“确认并保存此范围”。任何范围、台阶链或核验信息修改都会撤销确认。
- 点击“下载范围记录 JSON”。重开页面后通过“恢复 JSON”继续。浏览器备份仅为辅助，推荐下载文件备份。

## 保存含义

`workface_ranges.json` 保存版本、数据快照指纹、范围编号、上下特征线编号、两侧沿线区段、台阶节点链、核验人、备注、确认时间和三项核验勾选。

确认状态 `range_confirmed` 仅表示人工核实了所选范围，不表示参数已精度验证、生产状态已自动识别或安全达标。导入的确认是历史人工记录，不是本次程序自动确认。

编辑会立即把对应已保存记录降级为草稿，但只有点击“保存草稿”或“确认并保存”才更新该记录的范围内容；下载的是已保存记录。切换候选前请保存需要的编辑。

导入文件会完整校验后再合并；跨数据集、错误编号、重复编号、错误上下类型或无支持的已确认台阶链会拒绝。相同编号不会静默覆盖，请先删除旧记录再导入，或者在新打开的页面恢复。

## 当前边界

- 本轮只实现范围确认，没有更改正式 H1/L1/φ 计算和 SMSI。
- 紫色测线是原自动候选已通过几何检查且落在当前上下区段内的参考，不会随手动改边界在浏览器重新计算。改了边界或台阶链后，不再显示不适用的旧测线。
- “导出兼容预览 CSV”只能传递旧预览接口支持的上界区段和上下线编号，会丢失下界区段、链和确认状态。完整记录必须使用 JSON，CSV 不能作为已确认正式测量输入。
- 当前每个范围使用一条上部坡顶线和一条下部坡底线；不自动拼接多条碎线或跨缺测区域。
- 可靠台阶图之外的范围暂存草稿，需后续完善配对或边界，不放宽条件假造连接。
- 指纹用于防止误用数据，不是防伪数字签名；相同点云重新提取或精度改变也可能触发不匹配，届时需重新核验。
